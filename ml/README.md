# ML Modules (Stage 1 Foundation)

Directory structure reserved for Stages 4–6:
- `ml/forecasting/` — Seasonal Naive, Moving Average, Croston/TSB, LightGBM global model, N-HiTS optional extension
- `ml/pricing/` — Log-log price elasticity estimation, expiry markdown curve, competition & stock-pressure signals
- `ml/evaluation/` — Rolling-origin backtesting (WAPE, MAE, RMSE, MASE) and pricing policy simulations
- `ml/datasets/` — Deterministic synthetic feature builders (`SYNTHETIC_SEED=42`)
